## 修改位置

1. 打开 [项目主页](https://github.com/EpochTX/freegame)。
2. 在右侧的 **About** 区域点击齿轮按钮。
3. 填入 Description、Website、Topics 并保存。

## 主页结构说明

项目首页是 [README.md](../README.md)，活动清单保存在 [FREE_GAMES.md](../FREE_GAMES.md)。Actions 状态徽章会显示最近一次相关工作流运行结果；不表示所有游戏数据源始终正常。

项目只做自动**发现和通知**，不应该写成「100% 自动领游戏」，因为目前不会代领或登录游戏账号。
